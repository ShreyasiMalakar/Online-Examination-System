# 🎓 Institutional Online Examination System

A full-stack web-based Online Examination System developed using **Python Flask**, **MySQL**, **HTML/CSS**, and **Bootstrap**.  
The platform supports role-based authentication for **Students** and **Teachers**, allowing online test creation, participation, automatic evaluation, analytics, and leaderboard ranking.

---

## 🚀 Features

### 👨‍🎓 Student Features
- Secure Login & Registration
- Subject-wise Online Tests
- Randomized Questions
- Timer-based Examination
- Automatic Score Evaluation
- Result History
- Leaderboard & Rankings
- Responsive UI for Desktop & Mobile

### 👩‍🏫 Teacher Features
- Teacher Authentication
- Create Questions by Subject
- Manage Question Bank
- View Student Results
- Analytics Dashboard
- Class Performance Monitoring

## ⚙️ Installation & Setup

### 1️⃣ Clone Repository

```bash
git clone https://github.com/your-username/online-examination-system.git
```

### 2️⃣ Navigate to Project Folder

```bash
cd online-examination-system
```

### 3️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

### 4️⃣ Configure MySQL Database

Create database:

```sql
CREATE DATABASE app_db;
```

Import required tables using phpMyAdmin or MySQL.

### 5️⃣ Run Application

```bash
python app.py
```

Open browser:

```plaintext
http://127.0.0.1:5000
```
